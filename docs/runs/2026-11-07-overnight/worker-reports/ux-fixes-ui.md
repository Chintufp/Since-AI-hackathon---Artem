# UX fixes — ui area (src/libs/utils/ui/**)

- M1 (= fidelity-04, shell-10): new `ui/focus.ts` (`focusOptions(via)` passes `focusVisible:false` after a pointer action and `true` after a keyboard one, feature-detected with `probeFocusVisible`; `trackModality` reads the last pointerdown / keydown); in panel.ts `closePanel`, `focusFor`, `openPanel` and the two inline focus calls use it, Escape passes 'keyboard', the companion's toggle / open / close hooks pass 'pointer'. Tests: ui/focus.test.ts.
- M2 (= statemachine-no-recovery-when-raf-stops, fidelity-02, shell-02 companion part): companion.ts `animate()` takes a per-job `finish` (place at the end position), and a 'frame-watchdog' timer (`COMPANION.FRAME_WATCHDOG_MS` = 1000) is re-armed on every rAF tick of a job or watcher. `flush()` completes the job, any job its `done` chains (roll → tuck → toAway, roll → hop → finish), and the watchers. New `Companion.resume()` (wired to window focus, pageshow, visibilitychange→visible) flushes when the last frame is older than `RESUME_STALE_MS` = 250. Tests: companion.test.ts "M2 watchdog …" ×3, "M2 resume", "attachCompanion: …".
- M2 + statemachine-fall-onsettled-dropped: companion.ts release() adds a 'fall' guard, re-armed on every onStep/onLand, that settles him on the floor (place(bodyX,0), state 'in') when steps stop. On the floor it waits while the landing act's frames still advance. settled() is idempotent, a fallToken ignores late callbacks, and pointerDown clears it. Test: "M2 + fall …".
