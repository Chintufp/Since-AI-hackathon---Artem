# Experiment plan — frozen before results

Written before any scored run. Criteria below are provisional run-level acceptance rules (U07 stays open); they decide which configuration ships behind a setting tonight, not what the product adopts.

Common rules: E00 evaluator and splits are frozen first. Validation families are used for tuning; test families are scored once at the end, with criteria fixed here. Three seeds for anything stochastic. Hidden truth enters only the benchmark harness. Every run writes `experiments/results/<id>/manifest.json` and `results.json` with denominators and failure examples. Simulated people are simulated; nothing here measures real engineer benefit (U04).
